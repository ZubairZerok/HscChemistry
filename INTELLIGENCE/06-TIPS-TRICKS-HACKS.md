## 🔥 GUARANTEED MARK-SCORING TRICKS

### Trick 1: Math CQs = FREE MARKS (If you follow this format)
```
✅ CORRECT FORMAT:
দেওয়া আছে (Given):
    [List all given values with units]
    
নির্ণেয় (To Find):
    [What we need to find]
    
আমরা জানি (We know):
    [Write the formula]

প্রতিস্থাপন করি (Substituting):
    [Plug in numbers]

∴ উত্তর (Answer):
    [Final answer WITH UNITS] ← This is CRUCIAL!
```

**Why this works:** Examiners give partial marks for format even if calculation has minor errors!

### Trick 2: Organic Reactions = Write Conditions or Die
```
❌ WRONG (Loses 1 mark):
CH₃CH₂OH → CH₂=CH₂

✅ CORRECT (Full marks):
                    conc. H₂SO₄
CH₃CH₂OH ──────────────────→ CH₂=CH₂ + H₂O
                     170°C
```

## 🧠 MCQ SPEED TRICKS

### Trick 5: Elimination Strategy
When stuck on an MCQ:
1. **Eliminate 2 obviously wrong options** immediately
2. Between remaining 2, **apply the rule/exception** you know
3. **If still unsure, go with the more specific answer**
4. **NEVER leave blank** — there's no negative marking!

### Trick 6: Quick pH Shortcuts
| Solution | pH |
|----------|-----|
| 0.01M HCl | pH = -log(0.01) = **2** |
| 0.001M HCl | pH = **3** |
| 0.1M NaOH | pOH = 1, pH = **13** |
| Pure water | pH = **7** |
| 10⁻⁵M H⁺ | pH = **5** |

**Pattern:** For strong acid HCl with concentration 10⁻ⁿ M, pH = n (directly!)

### Trick 7: Oxidation Number Quick Rules
1. Free element = 0 (Na, O₂, S₈)
2. Monoatomic ion = charge (Na⁺ = +1)
3. O = -2 (except in peroxide = -1, OF₂ = +2)
4. H = +1 (except in metal hydrides = -1)
5. F = -1 (always)
6. Sum of all = charge of species

### Trick 8: Hybridization Quick Count
**Steric Number = σ bonds + lone pairs**
| Steric # | Hybridization |
|----------|--------------|
| 2 | sp |
| 3 | sp² |
| 4 | sp³ |
| 5 | sp³d |
| 6 | sp³d² |

## 🎯 TOPIC-SPECIFIC HACKS

### Hack 1: Kp = Kc Shortcut
When Δn = 0 (equal moles of gas on both sides): **Kp = Kc always!**
Examples: H₂ + I₂ ⇌ 2HI (Δn = 0)

### Hack 2: Le Chatelier Memory Trick — "RCTPC"
- **R**aise concentration of reactant → Forward ➡️
- **C**ut concentration of reactant → Backward ⬅️
- **T**emperature up + exothermic → Backward ⬅️
- **P**ressure up → Side with fewer moles
- **C**atalyst → NO SHIFT (only faster!)

### Hack 3: Directing Group Memory — "NHO-Meta-NO"
- **N**H₂, **H**alogen, **O**H → Ortho/Para directors
- **N**O₂, **C**OOH, **C**HO → Meta directors
- Think: "Electron donors activate (o/p), electron withdrawers deactivate (meta)"

### Hack 4: Faraday Calculation Shortcut
If you memorize that **1 Faraday (96500 C) deposits 1 equivalent weight:**
- 1F deposits: 108g Ag, 31.75g Cu, 9g Al, 32.7g Zn
- For 2F: double these values
- For 0.5F: halve these values

### Hack 5: Common Ion Colors (MCQ Gold!)
| Ion | Color |

| Cu²⁺ | Blue |
| Fe³⁺ | Yellow/Brown |
| Fe²⁺ | Green |
| Mn²⁺ | Light Pink |

### Hack 6: Remembering Electrode Potential Series
"**L**i **K** **Ba** **Ca** **Na** **Mg** **Al** **Zn** **Fe** **Ni** **Sn** **Pb** **H** **Cu** **Hg** **Ag** **Pt** **Au**"

Memory trick (Bangla): "লি-কে বা-কা না-ম-আল, জি-ফে-নি-স-পি-H, কু-হ-র-প-সো"

**Rule:** Elements ABOVE hydrogen → Easily oxidized (good reducing agents)
Elements BELOW hydrogen → Easily reduced (good oxidizing agents)

## 📝 WRITING TIPS FOR MAXIMUM MARKS

### 1. Answer ক (1 mark) — Be Surgical
- One clear sentence
- Include the textbook definition
- Example: "pH হলো কোনো দ্রবণে হাইড্রোজেন আয়নের (H⁺) ঘনমাত্রার ঋণাত্মক লগারিদম।"

### 2. Answer খ (2 marks) — Explain with Logic
- Write 2-3 sentences
- Include a formula or example if relevant
- Show you UNDERSTAND, not just memorized

### 3. Answer গ (3 marks) — Show EVERY Step
- Math problems: Given → Formula → Substitution → Calculation → Answer (with units!)
- Reactions: Write balanced equation with ALL conditions
- 1 mark per correct step (formula, substitution, answer)

### 4. Answer ঘ (4 marks) — Go Deep
- Write 4 distinct points or a full analysis
- Use comparison tables when possible
- Show real-life application or industrial importance
- Conclude with a summary statement

| Mistake | Where | Marks Lost |
|---------|-------|------------|
