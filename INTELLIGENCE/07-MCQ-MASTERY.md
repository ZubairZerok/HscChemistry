## 📘 Chemistry 1st Paper — MCQ Hotspots

### 1. Quantum Numbers (2-3 MCQs every exam!)

**Quick Check: Is this set valid?**
| n | l | m | s | Valid? | Why? |
|---|---|---|---|--------|------|
| 2 | 0 | 0 | +½ | ✅ | 2s orbital |
| 3 | 2 | -1 | -½ | ✅ | 3d orbital |
| 2 | 2 | 0 | +½ | ❌ | l can't equal n |
| 1 | 0 | 1 | +½ | ❌ | m can't exceed l |
| 0 | 0 | 0 | +½ | ❌ | n can't be 0 |

**Rules:** n ≥ 1, l = 0 to n-1, m = -l to +l, s = ±½

### 2. Electronic Configuration (1-2 MCQs)

**Quick Reference for Tricky Ones:**
| Element | Expected | Actual | Reason |
|---------|----------|--------|--------|
| Cr (24) | [Ar]3d⁴4s² | [Ar]3d⁵4s¹ | Half-filled d |
| Cu (29) | [Ar]3d⁹4s² | [Ar]3d¹⁰4s¹ | Full d |
| Fe²⁺ (26) | — | [Ar]3d⁶ | Remove 4s first! |
| Cu²⁺ (29) | — | [Ar]3d⁹ | Remove 4s first! |

**Key Rule:** When making ions, remove electrons from **outermost shell first** (4s before 3d!)

## 📗 Chemistry 2nd Paper — MCQ Hotspots

### 1. IUPAC Naming (2-3 MCQs!)

**Functional Group Priority (for naming):**
-COOH > -SO₃H > -COOR > -COX > -CONH₂ > -CHO > >C=O > -OH > -NH₂ > C=C > C≡C

**Common Traps:**
| Structure | Correct Name | Common Wrong Answer |
|-----------|-------------|-------------------|
| CH₃CH₂CH(CH₃)CH₂CH₃ | 3-Methylpentane | 3-Methylhexane |
| CH₃CH=CHCH₃ | But-2-ene | 2-Butene (acceptable) |
| CH₂=CHCH₂OH | Prop-2-en-1-ol | Allyl alcohol |
| CH₃COCH₃ | Propan-2-one | Dimethyl ketone |

### 2. Isomer Counting

| Formula | # of Structural Isomers |
|---------|------------------------|
| C₄H₁₀ | 2 (n-butane, isobutane) |
| C₅H₁₂ | 3 (n-pentane, isopentane, neopentane) |
| C₄H₈ | 4 (but-1-ene, but-2-ene, 2-methylpropene, cyclobutane) |
| C₂H₆O | 2 (ethanol, dimethyl ether) |
| C₃H₆O | 3+ (propanone, propanal, allyl alcohol...) |

### 3. Markovnikov vs Anti-Markovnikov

| Reaction | Product |
|----------|---------|
| CH₃CH=CH₂ + HBr | CH₃CHBrCH₃ (Markovnikov — H to more H) |
| CH₃CH=CH₂ + HBr + peroxide | CH₃CH₂CH₂Br (Anti-Markovnikov) |
| CH₃CH=CH₂ + H₂O/H⁺ | CH₃CH(OH)CH₃ (Markovnikov) |
| CH₃CH=CH₂ + HCl | CH₃CHClCH₃ (Markovnikov) |

**⚠️ Anti-Markovnikov ONLY works with HBr + peroxide! NOT with HCl or HI!**

### 5. Gas Law MCQ Traps

**Common Trap:** Forgetting to convert temperature to Kelvin!
- 27°C = 300 K
- 0°C = 273 K  
- 100°C = 373 K

**Another Trap:** Using wrong R value!
- If P in atm, V in L → R = **0.0821** L·atm·K⁻¹·mol⁻¹
- If P in Pa, V in m³ → R = **8.314** J·K⁻¹·mol⁻¹

### 6. BOD/COD/TDS Quick Reference

## 🎯 MCQ Power Patterns

### Pattern 1: "Which of the following is CORRECT?"
→ Look for the ONE TRUE statement. The other 3 will have subtle errors.

### Pattern 2: "Which CANNOT be true?"
→ Look for the EXCEPTION. Three options follow a rule, one breaks it.

### Pattern 3: Calculation MCQ
→ If you can't solve in 60 seconds, **estimate the answer range** and eliminate:
- If answer should be small (like pH of acid), eliminate options >7
- If answer should be negative (like E° of active metal), eliminate positive options

### Pattern 4: "Among the following, the HIGHEST/LOWEST is..."
→ For IE, EA, EN: Remember periodic trends + exceptions
→ For boiling point: H-bonding > dipole-dipole > London forces
