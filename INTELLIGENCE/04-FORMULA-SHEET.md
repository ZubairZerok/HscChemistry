## ⚛️ ATOMIC STRUCTURE & SPECTRUM

| Formula | Description |
|---------|-------------|
| $E_n = -13.6/n^2$ eV | Energy of nth orbit (H atom) |
| $r_n = 0.529 \times n^2$ Å | Radius of nth orbit (H atom) |
| $1/\lambda = R(1/n_1^2 - 1/n_2^2)$ | Rydberg formula (R = 1.097×10⁷ m⁻¹) |
| $E = h\nu = hc/\lambda$ | Energy of photon |
| $c = \nu\lambda$ | Speed of light = frequency × wavelength |

## 🔗 CHEMICAL BONDING

| Formula | Description |
|---------|-------------|
| Bond Order = (Nb - Na)/2 | MOT bond order |
| Steric No. = bonds + lone pairs | Determines hybridization |
| Dipole moment: $\mu = q \times d$ | Charge × distance |

## ⚖️ CHEMICAL EQUILIBRIUM

| Formula | Description |
|---------|-------------|
| $K_c = [C]^c[D]^d / [A]^a[B]^b$ | Equilibrium constant (concentration) |
| $K_p = K_c(RT)^{\Delta n}$ | Kp-Kc relation (R = 0.0821, T in K) |
| $\Delta n = \Sigma n_{products} - \Sigma n_{reactants}$ | For gaseous species only |
| $K_w = [H^+][OH^-] = 10^{-14}$ | Ionic product of water (25°C) |

## 🧪 pH & BUFFERS

| Formula | Description |
|---------|-------------|
| $pH = -\log[H^+]$ | pH definition |
| $pOH = -\log[OH^-]$ | pOH definition |
| $pH + pOH = 14$ | At 25°C |
| $pH = pK_a + \log([\text{Salt}]/[\text{Acid}])$ | Henderson (acidic buffer) |
| $pOH = pK_b + \log([\text{Salt}]/[\text{Base}])$ | Henderson (basic buffer) |
| $pK_a = -\log K_a$ | Acid dissociation constant |
| $pK_a + pK_b = 14$ | Conjugate acid-base pair |

## 🌡️ THERMOCHEMISTRY

| Formula | Description |
|---------|-------------|
| $\Delta G = \Delta H - T\Delta S$ | Gibbs free energy |
| $\Delta G < 0$ → Spontaneous | Feasibility check |
| $\Delta H = \Sigma\Delta H_f(products) - \Sigma\Delta H_f(reactants)$ | Hess's Law |
| $q = mc\Delta T$ | Heat = mass × specific heat × temp change |

## 💨 GAS LAWS

| Formula | Description |
|---------|-------------|
| $PV = nRT$ | Ideal gas equation |
| $P_1V_1 = P_2V_2$ | Boyle's Law (const T) |
| $V_1/T_1 = V_2/T_2$ | Charles's Law (const P) |
| $P_{total} = P_1 + P_2 + P_3...$ | Dalton's partial pressure |
| $P_i = \chi_i \times P_{total}$ | Partial pressure from mole fraction |
| $r_1/r_2 = \sqrt{M_2/M_1}$ | Graham's law of diffusion |

## 🔋 ELECTROCHEMISTRY

| Formula | Description |
|---------|-------------|
| $E°_{cell} = E°_{cathode} - E°_{anode}$ | Standard cell potential |
| $E = E° - (0.0591/n)\log Q$ | Nernst equation (25°C) |
| $W = MIt/(nF)$ | Faraday's 1st law (mass deposited) |
| $W_1/W_2 = E_1/E_2$ | Faraday's 2nd law (series cells) |
| $E = M/n$ | Equivalent weight |
| F = 96500 C/mol | Faraday constant |

## 📏 CONCENTRATION

| Formula | Description |
|---------|-------------|
| $M = n/V_L$ | Molarity (mol/L) |
| $m = n/W_{kg}$ | Molality (mol/kg solvent) |
| $N = eq/V_L$ | Normality (eq/L) |
| $N = n \times M$ | Normality-Molarity relation |
| $V_1S_1 = V_2S_2$ | Dilution formula |
| $ppm = mg/L$ or $mg/kg$ | Parts per million |

## 🧫 TITRATION

| Formula | Description |
|---------|-------------|

| % yield = (actual/theoretical) × 100 | Yield calculation |

## 🔬 SOLUBILITY

| Formula | Description |
|---------|-------------|

| If $K_{ip} > K_{sp}$ → Precipitation | Precipitation condition |
| If $K_{ip} < K_{sp}$ → No precipitation | Solution unsaturated |
