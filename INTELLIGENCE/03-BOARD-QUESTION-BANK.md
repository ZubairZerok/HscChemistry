## 📘 CHEMISTRY 1ST PAPER — Board Questions Collection

### Chapter 2: Qualitative Chemistry

#### CQ Type 1: Bohr Model & Spectrum Calculation
**Question Pattern:** "An electron jumps from n=5 to n=2 in hydrogen atom. Calculate wavelength."

**Solution Template:**
```
Given: n₁ = 2, n₂ = 5, R = 1.097 × 10⁷ m⁻¹
Formula: 1/λ = R(1/n₁² - 1/n₂²)
1/λ = 1.097 × 10⁷(1/4 - 1/25)
1/λ = 1.097 × 10⁷ × 21/100
1/λ = 1.097 × 10⁷ × 0.21
1/λ = 2.3037 × 10⁶
λ = 4.341 × 10⁻⁷ m = 434.1 nm
This falls in Balmer series (Visible region, violet color)
```

#### CQ Type 2: Ksp & Precipitation
**Question Pattern:** "Will precipitation occur when 100 mL of 0.001M AgNO₃ is mixed with 100 mL of 0.001M NaCl? (Ksp of AgCl = 1.8 × 10⁻¹⁰)"

**Solution Template:**
```
After mixing, volume doubles → concentrations halve
[Ag⁺] = 0.001/2 = 5 × 10⁻⁴ M
[Cl⁻] = 0.001/2 = 5 × 10⁻⁴ M
Kip = [Ag⁺][Cl⁻] = 5×10⁻⁴ × 5×10⁻⁴ = 2.5 × 10⁻⁷
Since Kip (2.5×10⁻⁷) > Ksp (1.8×10⁻¹⁰)
∴ Precipitation WILL occur ✅
```

### Chapter 3: Periodic Properties & Bonding

#### CQ Type 3: Hybridization Prediction
**Question Pattern:** "Determine hybridization, shape, and bond angle of PCl₅"

**Solution Template:**
```
P in PCl₅: Valence electrons = 5
Bonds formed = 5, Lone pairs = 0
Steric number = 5 + 0 = 5
Hybridization = sp³d
Shape = Trigonal Bipyramidal
Bond angles = 120° (equatorial) and 90° (axial-equatorial)
```

#### CQ Type 4: Periodic Trend Explanation
**Question Pattern:** "Why is ionization energy of N greater than O?"
```
N: 1s²2s²2p³ — has HALF-FILLED 2p subshell (extra stability)
O: 1s²2s²2p⁴ — one 2p orbital has paired electrons (repulsion)
Removing an electron from O is easier because:
1. Paired electron repulsion in O's 2p
2. Half-filled stability in N's 2p requires more energy to disrupt
∴ IE(N) > IE(O)
```

### Chapter 4: Chemical Changes

#### CQ Type 5: Kp-Kc Calculation (APPEARS EVERY EXAM!)
**Question Pattern:** "2 moles of SO₂ and 1 mole of O₂ are placed in a 1L vessel at 500K. At equilibrium, 0.6 moles of SO₃ are formed. Find Kc and Kp."

**Solution Template:**
```
Reaction: 2SO₂(g) + O₂(g) ⇌ 2SO₃(g)

ICE Table:
              2SO₂  +  O₂  ⇌  2SO₃
Initial:       2       1       0
Change:       -0.6    -0.3    +0.6
Equilibrium:   1.4     0.7     0.6

[SO₂] = 1.4/1 = 1.4 M
[O₂] = 0.7/1 = 0.7 M
[SO₃] = 0.6/1 = 0.6 M

Kc = [SO₃]²/([SO₂]²[O₂])
Kc = (0.6)²/((1.4)² × 0.7)
Kc = 0.36/(1.96 × 0.7)
Kc = 0.36/1.372 = 0.2624

Δn = 2 - (2+1) = -1
Kp = Kc(RT)^Δn = 0.2624 × (0.0821 × 500)^(-1)
Kp = 0.2624 / 41.05 = 0.00639
```

#### CQ Type 6: Buffer pH Calculation (APPEARS EVERY EXAM!)
**Question Pattern:** "Calculate pH when 50 mL of 0.1M CH₃COOH is mixed with 75 mL of 0.2M CH₃COONa. Ka = 1.8×10⁻⁵"

**Solution Template:**
```
pKa = -log(1.8 × 10⁻⁵) = 4.745

Millimoles of acid = 50 × 0.1 = 5 mmol
Millimoles of salt = 75 × 0.2 = 15 mmol

pH = pKa + log(salt/acid)
pH = 4.745 + log(15/5)
pH = 4.745 + log(3)
pH = 4.745 + 0.477
pH = 5.222 ≈ 5.22
```

## 📗 CHEMISTRY 2ND PAPER — Board Questions Collection

### Chapter 1: Environmental Chemistry

#### CQ Type 7: Ideal Gas Law Problem
**Question Pattern:** "Find the volume of 5g of CO₂ at 27°C and 740 mmHg pressure"

**Solution Template:**
```
Given: m = 5g, M(CO₂) = 44 g/mol, T = 27+273 = 300K
P = 740 mmHg = 740/760 = 0.974 atm
n = m/M = 5/44 = 0.1136 mol

PV = nRT
V = nRT/P = (0.1136 × 0.0821 × 300) / 0.974
V = 2.797 / 0.974
V = 2.872 L
```

### Chapter 2: Organic Chemistry

#### CQ Type 8: Organic Conversion Chain
**Question Pattern:** "Starting from Ethanol, prepare Acetic acid. Show all steps."

**Solution Template:**
```
Step 1: Ethanol → Acetaldehyde (Oxidation)
CH₃CH₂OH + [O] →(K₂Cr₂O₇/H₂SO₄) CH₃CHO + H₂O

Step 2: Acetaldehyde → Acetic Acid (Further oxidation)
CH₃CHO + [O] →(K₂Cr₂O₇/H₂SO₄) CH₃COOH
```

#### CQ Type 9: Compound Identification (A, B, C)
**Question Pattern:** 
"A is an unsaturated hydrocarbon. When A reacts with HgSO₄/H₂SO₄ in presence of water, compound B is formed. B gives positive iodoform test and silver mirror test. Identify A and B."

**Solution Template:**
```
B gives:
- Silver mirror test → B has -CHO group (Aldehyde)
- Iodoform test → B has CH₃CO- or CH₃CH(OH)- group

B gives BOTH → B = CH₃CHO (Acetaldehyde)

B is formed from A by hydration (HgSO₄/H₂SO₄):
A + H₂O →(HgSO₄, H₂SO₄) CH₃CHO

∴ A = CH≡CH (Acetylene/Ethyne)
   B = CH₃CHO (Acetaldehyde/Ethanal)
```

#### CQ Type 10: Distinction Between Compounds
**Question Pattern:** "How would you distinguish between Acetaldehyde and Acetone?"

**Solution Template:**
```
Test 1: Tollens' Test (Silver Mirror Test)
- Acetaldehyde + Tollens' reagent → Silver mirror (positive) ✅
- Acetone + Tollens' reagent → No reaction ❌

Test 2: Fehling's Test
- Acetaldehyde + Fehling's solution → Red precipitate (Cu₂O) ✅
- Acetone + Fehling's solution → No reaction ❌

Test 3: Schiff's Test
- Acetaldehyde + Schiff's reagent → Pink/Magenta color ✅
- Acetone + Schiff's reagent → No reaction ❌
```

### Chapter 3: Quantitative Chemistry

#### CQ Type 11: Redox Titration
**Question Pattern:** "What volume of 0.02M KMnO₄ is needed to titrate 25 mL of 0.05M FeSO₄ in acidic medium?"

**Solution Template:**
```
Balanced equation:
MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O

Mole ratio: MnO₄⁻ : Fe²⁺ = 1 : 5

Millimoles of Fe²⁺ = 25 × 0.05 = 1.25 mmol
Millimoles of KMnO₄ needed = 1.25/5 = 0.25 mmol
Volume of KMnO₄ = 0.25/0.02 = 12.5 mL
```

### Chapter 4: Electrochemistry

#### CQ Type 12: Faraday's Law Calculation (VERY FREQUENT!)
**Question Pattern:** "A current of 5A is passed through CuSO₄ solution for 30 minutes. Calculate mass of Cu deposited. (At. mass Cu = 63.5)"

**Solution Template:**
```
Given: I = 5A, t = 30 min = 1800 s, M = 63.5, n = 2 (Cu²⁺), F = 96500

W = MIt/(nF)
W = (63.5 × 5 × 1800) / (2 × 96500)
W = 571500 / 193000
W = 2.961 g

∴ Mass of Cu deposited = 2.96 g
```

#### CQ Type 13: Nernst Equation
**Question Pattern:** "Calculate EMF of cell: Zn|Zn²⁺(0.1M)||Cu²⁺(0.01M)|Cu. Given E°(Zn²⁺/Zn) = -0.76V, E°(Cu²⁺/Cu) = +0.34V"

**Solution Template:**
```
E°cell = E°cathode - E°anode = 0.34 - (-0.76) = 1.10 V
n = 2 (2 electrons transferred)

Cell reaction: Zn + Cu²⁺ → Zn²⁺ + Cu

Ecell = E°cell - (0.0591/n) × log([Zn²⁺]/[Cu²⁺])
Ecell = 1.10 - (0.0591/2) × log(0.1/0.01)
Ecell = 1.10 - 0.02955 × log(10)
Ecell = 1.10 - 0.02955 × 1
Ecell = 1.10 - 0.030
Ecell = 1.070 V
```

#### CQ Type 14: Series Electrolysis (Faraday's 2nd Law)
**Question Pattern:** "Two cells containing AgNO₃ and CuSO₄ are connected in series. If 1.08g Ag is deposited, find mass of Cu deposited."

**Solution Template:**
```
By Faraday's 2nd Law:
W₁/W₂ = E₁/E₂ = (M₁/n₁)/(M₂/n₂)

For Ag: M₁ = 108, n₁ = 1 → E₁ = 108
For Cu: M₂ = 63.5, n₂ = 2 → E₂ = 31.75

1.08/W₂ = 108/31.75
W₂ = 1.08 × 31.75/108
W₂ = 0.3175 g

∴ Mass of Cu deposited = 0.318 g
```
